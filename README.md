# EML - Verification - implementation - js
eml関数を木構造的に適用することによって初等関数を全てを実装できるそうです。

[All elementary functions from a single operator/Andrzej Odrzywołek(2026)](https://arxiv.org/html/2603.21852v2)

このリポジトリは、複素数計算とスタック演算を用いて論文中の計算をJavaScriptにて実装を検証したものです。

# 利用方法
ローカルに落として`$ node emltree.js`と実行してください。  
また、`index.html`をブラウザで立ち上げることで、コンソールに同様の結果が表示され、ブラウザ上でもいじれます。  
[こちら](https://hempgreens.github.io/EML-Verification-implementation-js/)のページですぐに試せます。
